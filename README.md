# 瑜伽课堂助手 V1.0 — 第一阶段

原生 HTML / CSS / JavaScript 的可运行独立原型，不依赖 npm、数据库或第三方服务。

## 运行

推荐 Python 3：在本目录运行 `python -m http.server 8000`（Windows 也可用 `py -m http.server 8000`），然后浏览器访问 `http://localhost:8000`。请不要直接双击 `index.html`，因为 ES Modules 在 file:// 下通常会被浏览器安全策略阻止。

同一局域网手机访问：将服务器绑定至局域网可访问地址，并在手机打开 `http://电脑局域网IP:8000`；请仅在可信网络中操作。此原型无登录鉴权，不应公开暴露到互联网。

## 文件结构

- `index.html`：页面结构和对话框
- `css/style.css`：响应式样式
- `js/app.js`：课程编排、保存、备份、课堂计时
- `js/poses.js`：12个示例体式及审核状态
- `js/assets.js`：Liny V3.2 素材映射与缺图回退
- `assets/liny/`：正式审核图片放置目录（当前未附带母版）

## Liny素材接入

将用户已验收的**原始** PNG 文件分别命名为：
- `assets/liny/tadasana.png`
- `assets/liny/vrksasana.png`
- `assets/liny/virabhadrasana-ii.png`

如需不同命名或格式，修改 `js/assets.js` 中的路径。文件缺失时显示文字占位。V3.2体式审核状态已记录，但图片文件**未提供**。其余9个体式仅为编排用示例，尚无Liny审核素材。

## 功能验收

1. 进入课程编排，设置名称、目标60分钟、难度和备注。
2. 点击添加体式，选择山式、树式、战士二式，确认序列显示。
3. 修改任一动作分钟数，确认总时长和与目标差额实时更新。
4. 用上下箭头调整顺序，删除一个体式，再重新添加。
5. 点击保存课程，刷新网页后到“我的课程”打开，检查数据仍在。
6. 在“我的课程”点击复制，确认副本具有独立ID、可单独编辑和保存。
7. 打开课堂模式，确认当前/下个体式、倒计时、暂停、重置、切换工作。
8. 未放入Liny图片时，应显示占位文字；放入上述正式文件后应加载对应图片。
9. 导出 JSON，再在新的浏览器环境中导入，确认课程可恢复。
10. 在手机窄屏检查导航、课程编辑与课堂模式是否可用。

## 数据模型

课程 `{id,title,targetMinutes,level,notes,items,createdAt,updatedAt}`；动作 `{id,poseId,seconds,note}`；体式定义位于 `js/poses.js`。课程保存于浏览器 localStorage，备份可导出 JSON。

## 限制与待办

- 无后端、微信登录、云同步、AI生成、支付或正式微信小程序包。
- 未提供Liny正式图片；只实现了素材接入路径及缺图占位。
- 12个示例体式并不等于12个经过专业审核的教学动作；仅首批3个登记为已验收。
- 计时器只对当前体式计时，完成后手动切换；没有后台通知、语音提示或自动连播。
- 课程时长按各体式设置的秒数求和；没有自动加入转场时间、双侧动作补偿或休息段。
- localStorage 可能被清理；请定期导出备份。导入数据请仅使用可信文件。
- 这是依据既定功能规格新建的兼容原型，不是对不可用旧源文件的逐行修改。
